# 更新文档

以“真实来源”为准同步文档（优先读代码与配置，而不是凭记忆写）。

1. 读取 `package.json` 的 scripts
   - 生成脚本清单表
2. 读取 `.env.example`
   - 列出所有环境变量及用途/格式
3. 生成/更新 `docs/CONTRIB.md`
   - 开发流程、可用脚本、环境准备、测试方式
4. 生成/更新 `docs/RUNBOOK.md`
   - 部署流程、监控告警、常见问题与修复、回滚
5. 标出可能过期的文档
   - 90 天未更新的文件列表（供人工确认）
6. 输出改动摘要（diff）

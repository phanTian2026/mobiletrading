# /learn（提炼可复用模式）

把本次会话里“值得复用的解法/套路”提炼出来，保存成可重复使用的技能说明。

## 什么时候用

解决了一个不简单的问题后，随时运行 `/learn`。

## 提炼什么

- 错误解决套路：现象 → 根因 → 修复点
- 调试步骤：哪些检查顺序最有效、哪些工具组合好用
- 规避方案：某个库/版本的坑如何绕开
- 项目惯例：本项目的目录/命名/工作流约定

## 输出格式

在 `skills/learned/` 新建一个文件：

```markdown
# 模式名

**日期：** YYYY-MM-DD
**适用场景：** 一句话说明

## 问题
要解决的具体问题

## 解法
可复用步骤/关键点

## 示例
可选：代码或命令
```

## 规则

- 不记录小修小补（拼写、简单语法错）
- 不记录一次性问题
- 一份文件只写一个模式

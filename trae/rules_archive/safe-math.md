# 除法安全规则

## 核心原则

在所有涉及数据处理的代码中（尤其是因子库、策略库、信号库），所有除法运算 `A / B` 必须统一写成 `A / (B + eps)` 的形式，以防止分母为 0 或极小导致计算异常（如 `inf` 或 `NaN`）。

## 默认参数

- `eps = 1e-8` （除非有特殊精度要求，否则统一使用此值）

## 代码示例

### ✅ 正确写法

```python
# 推荐写法
df['factor'] = df['numerator'] / (df['denominator'] + 1e-8)

# 复杂表达式
df['ratio'] = (df['A'] - df['B']) / (df['C'] * df['D'] + 1e-8)

# 涉及变量
eps = 1e-8
result = x / (y + eps)
```

### ❌ 错误写法

```python
# 禁止直接除
df['factor'] = df['numerator'] / df['denominator']

# 禁止仅判断不加保护（容易遗漏）
# if df['denominator'] != 0: ...
```

## 适用范围

- **因子库 (`因子库/*.py`)**：所有因子计算逻辑。
- **策略库 (`策略库/*.py`)**：所有策略内的指标计算。
- **信号库 (`信号库/*.py`)**：所有择时信号计算。
- **数据预处理脚本**：任何涉及 pandas DataFrame 列运算的地方。

## 例外情况

1.  **分母为非零常数**：
    ```python
    df['ma'] = df['close'] / 100  # ✅ 允许
    avg = total / 5.0             # ✅ 允许
    ```
2.  **逻辑上绝对不可能为 0 的数学函数**（需谨慎）：
    ```python
    df['y'] = 1 / (np.exp(df['x']) + 1)  # exp(x)+1 > 1，通常安全
    ```
    *建议：即使是这种情况，为了统一规范，加上 `+ 1e-8` 也是可以接受的。*

## 自动修复建议

如果发现遗漏，请优先使用以下正则表达式进行查找和替换（需人工确认）：

- 查找：`(\s*/\s*)([^0-9\s(][^+\-*/\n]*)`
- 替换提示：需人工判断分母边界，手动添加 `( ... + 1e-8)`

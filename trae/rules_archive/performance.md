# 性能与模型选择

## 模型选择建议

**Haiku 4.5**（轻量、省成本）：
- 频繁调用的小任务
- 结对式写代码与常规生成
- 多角色协作中的“工人”任务

**Sonnet 4.5**（主力写代码）：
- 主要开发工作
- 组织多角色工作流
- 中高复杂度编码任务

**Opus 4.5**（最强推理）：
- 架构决策
- 高推理需求任务
- 研究与深度分析

## 上下文窗口管理

避免在上下文窗口最后 20% 做：
- 大规模重构
- 跨多文件的大功能
- 复杂交互调试

上下文不敏感的任务（更适合后半段）：
- 单文件小改动
- 独立小工具
- 文档更新
- 简单 bug 修复

## 深度思考与 Plan 模式

默认开启深度思考（保留最多 31,999 tokens 供内部推理）。

常用控制方式：
- 开关：Option+T（macOS）/ Alt+T（Windows/Linux）
- 配置：`settings.json` 里的 `alwaysThinkingEnabled`
- 上限：`export MAX_THINKING_TOKENS=10000`
- 查看推理输出：Ctrl+O

高复杂任务建议流程：
1. 确保深度思考开启
2. 开启 Plan 模式先做结构化拆解
3. 做多轮自检/复盘
4. 必要时拆分多个子角色并行处理

## 构建失败排查

构建失败时：
1. 使用 build-error-resolver 角色
2. 先读错误信息
3. 小步修复
4. 每次修复后立刻验证

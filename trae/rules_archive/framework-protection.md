# 框架保护规则

## 核心原则：不修改框架代码

邢不行选股框架（select-stock-pro）的核心代码是上游维护的，后期需要合并新版本。
**严禁直接修改框架文件**，避免合并冲突。

## 🚫 禁止修改的目录/文件（未经用户确认）

- `core/` — 回测引擎核心
- `program/` — 回测分步脚本（第 1 步 ~ 第 4 步）
- `constant.py` — 常量定义
- `回测主程序.py` / `回测主程序_增强版.py`
- `寻找最优参数.py` / `寻找最优定风波组合参数.py`
- `批量回测主程序*.py`
- `选股+回测.py`
- `策略报告启动器Pro.py`

## ✅ 允许自由创建/修改的内容

- `因子库/` — 新建因子文件（不修改已有因子）
- `策略库/` — 新建策略文件（不修改已有策略）
- `信号库/` — 新建信号文件（不修改已有信号）
- `config.py` — 全局配置入口
- `env.py` — 环境变量配置
- `config库/` — 配置文件（新建或修改均可）
- `tools/` — 新建工具脚本
- `tests/` — 测试文件
- `data/` — 数据文件
- `logs/` — 日志
- `.trae/` — AI 配置和技能
- 项目根目录下新建的独立脚本

## 📝 AI 创建文件的标记规范

所有 AI 创建的新文件必须在文件头部包含标记：

```python
"""
[AI-GENERATED] 本文件由 AI 辅助创建，非框架原始文件。
创建目的：[简要说明用途]
"""
```

对于非 Python 文件（如 .md、.sh）：

```markdown
<!-- [AI-GENERATED] 本文件由 AI 辅助创建，非框架原始文件。 -->
```

## ⚠️ 必须修改框架时的流程

如果确实需要修改框架文件（上述禁止列表中的文件）：

1. **停下来**，向用户说明：为什么必须修改、修改哪个文件、改动内容
2. **等待用户明确确认**后才能执行修改
3. 修改时在变更处添加注释标记：`# [AI-MODIFIED] 说明原因`
4. 尽量使改动最小化，方便未来 merge 时识别和处理

## 💡 优先采用的替代方案

遇到需要扩展功能时，优先考虑：

1. **新建独立脚本** — 而非修改现有入口文件
2. **新建因子/策略文件** — 而非修改已有的
3. **新建 config 文件** — 而非修改现有 config
4. **包装器模式** — 创建 wrapper 脚本调用框架功能
5. **env.py 配置** — 利用已有的环境变量机制
